# Nothing

* Вердикт **ℹ️ «Пока безопасно» :trollface:**
* [**🔓️ Руководство по разблокировке**](../../misc/generic-unlock.md)

Телефоны Nothing можно разблокировать через fastboot без каких-либо кодов. Единственное требование — включить **OEM unlocking** на странице настроек **Developer Options**. Это та же процедура, что и на Google Pixel.

Сообщается, что телефоны Nothing поддерживают [кастомные ключи AVB](../../README.md#custom-avb-keys).
