# TP-Link/Neffos

* Вердикт: **ℹ️ «Пока безопасно» :trollface:**
* [**🔓️ Инструкция по разблокировке**](../../misc/generic-unlock.md)

Удивительно, что компания, известная своими роутерами, никогда не усложняла и не ограничивала разблокировку загрузчика на своих смартфонах.

TP-LINK/Neffos можно разблокировать через стандартный fastboot. И даже после прекращения выпуска смартфонов и закрытия подразделения Neffos **все ранее выпущенные модели всё ещё можно разблокировать, потому что процесс полностью офлайн** и не полагается на серверы производителя.

> *Press F to pay respect*

Отличный пример того, почему офлайн-разблокировка так важна.
