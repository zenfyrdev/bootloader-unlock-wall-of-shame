# AT&T/Cricket

- Вердикт: **🍅 Просто ужасно!**

AT&T не разрешает разблокировать загрузчик, пока телефон не разблокирован в сети, и у оператора есть история необоснованных отказов в сетевой разблокировке. При этом в некоторых недавних сообщениях на XDA утверждается, что загрузчик AT&T Pixel 9 можно разблокировать, если настроить телефон [без SIM-карты AT&T](https://xdaforums.com/t/at-t-pixel-9-pro-xl-bootloader-unlockable.4689083/). У AT&T также есть искусственный чёрный список, поэтому доступны только официально поддерживаемые оператором устройства. Лучше избегать AT&T.

Кроме того, дочерняя компания AT&T Cricket недавно начала [блокировать параметры разработчика](https://xdaforums.com/t/moto-g-power-2025-cricket-wireless-now-locks-developer-options-for-6-months.4731763/) на некоторых устройствах Motorola. Из-за этого невозможно использовать ADB или Shizuku.
