# Volla

* Вердикт: **ℹ️ «Пока безопасно» :trollface:**
* [**🔓️ Инструкция по разблокировке**](../../misc/generic-unlock.md)

Volla Phones (https://volla.online) можно разблокировать через fastboot без кодов. Единственное требование — включить **OEM unlocking** в настройках **Для разработчиков** (как на Google Pixel). Volla также предоставляет исходники ядра, а [вся их ОС — открытый исходный код](https://github.com/hellovolla).

Volla Phones поддерживает [кастомные AVB-ключи](../../README.md#custom-avb-keys).
