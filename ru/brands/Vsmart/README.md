# Vsmart (VinSmart)

- Вердикт: **⛔ Избегать любой ценой!**

Устройства Vsmart (VinSmart) в настоящее время невозможно разблокировать после ухода компании с мобильного рынка в мае 2021 года и последующего отключения всех серверов верификации. Ранние модели (Active 1/1+) на VOS 2.5 и ниже поддерживали стандартную разблокировку через fastboot, но VOS 3.0 удалил опцию «OEM Unlocking» и ввёл зависимые от серверов ограничения, которые теперь невозможно обойти. Большинство современных устройств (Aris, Live 4, Joy 4) остаются навсегда заблокированными. Единственный способ — использование MTKClient для моделей на MediaTek.
