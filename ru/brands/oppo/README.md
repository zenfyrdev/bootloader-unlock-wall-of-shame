## Realme

Realme разрешает разблокировку для поддерживаемых моделей и регионов. Подтверждена поддержка моделей из Китая и Индии, при этом, как сообщается, поддерживаются также некоторые модели из других регионов. 

Для разблокировки нужно отправить запрос через приложение deep testing, которое они публикуют на своём форуме. Вам придётся найти и следовать инструкциям на [c.realme.com](https://c.realme.com/in/). Процесс практически одинаков для большинства телефонов, но для более новых моделей может потребоваться аккаунт HeyTap.

Руководство: [xdaforums.com][Full-OTA region switch]

#### Эксплойт сервера (Устарел)

В апреле–мае 2023 года с помощью этого скрипта [rmx3474-rooting] можно было разблокировать любой телефон Realme, но 26 мая Realme опубликовала объявление на своём форуме [c.realme.com][announcement]. (Они удалили оригинальное объявление)
С тех пор они заставили свои серверы возвращать только ключи «new struct», к которым привязаны данные модели, что делает скрипт бесполезным.

## OPPO
>Если разблокировка загрузчика не работает на устройстве Oppo Mediatek с помощью модификации SECCFG (разблокировка через mtkclient), можно попробовать разблокировать fastboot, записав >модифицированный boot1 (preloader). Запись preloader также использует mtkclient: [oppo-mtk-fastboot-unlock](https://github.com/Shocked-Cat/oppo-mtk-fastboot-unlock).

Об OPPO больше сказать почти нечего. Они также предлагают углублённое тестирование, но только для китайских моделей.

## Deep Testing

Deep Testing — это приложение, используемое для запроса fastboot-ключа. Внутренне оно записывает ключ в раздел (oplus/oppo)reserve1, который позже считывается fastboot. У Realme и Oppo разные версии Deep Testing, но приложения почти идентичны по функциональности.

### Realme

Хотя посты Realme создают впечатление, что для каждого устройства нужна своя версия DT, это не так. Все устройства с RUI 2 и ниже должны использовать v1.0.0, все устройства с RUI 3 и выше — v1.0.1 или v1.1.0.

**v1.0.1:**
- Меняет ключ подписи.

**v1.1.0:**
- Вводит аккаунты HeyTap.

#### Отладка

Случайно была выпущена отлаживаемая версия Deep Testing 1.1.0. Имея Android Studio, вы можете выполнять код с полными системными привилегиями (UID 1000, не root).

На это указал [gargargar666 на XDA][deep-testing-thread]. Загрузите [GT5-DeepTesting.apk][debuggable-deep-testing]

### Oppo

Oppo Deep Testing использует другой API-эндпоинт для запроса кода разблокировки. Существует только 2 версии Oppo Deep Testing: v1.0.1 и v1.1.0.
