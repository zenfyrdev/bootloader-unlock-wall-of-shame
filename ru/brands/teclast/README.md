* [**🔓️ Инструкция по разблокировке (MediaTek)**](../../misc/generic-unlock.md)

Teclast — китайский бренд, известный бюджетными планшетами и, реже, Android-смартфонами.

Teclast следует [стандартной процедуре разблокировки](../../misc/generic-unlock.md) для устройств на MediaTek и Allwinner. Устройства на Unisoc не могут быть разблокированы — это *не* вина Teclast.

Teclast не публикует исходный код ядра — это нарушение GPLv2.
