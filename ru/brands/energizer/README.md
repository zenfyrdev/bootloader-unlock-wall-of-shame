# Energizer

- Вердикт: **🍅 Ужасно!**

Energizer не только уничтожит вашу электронику, протекая кислотой из батареек, но и уничтожит вашу конфиденциальность, не позволяя разблокировать загрузчик. Ни их Android-телефоны, ни KaiOS-телефоны не подлежат разблокировке.

Energizer не публикует исходный код ядра для своих устройств. Это нарушение лицензии GPLv2, используемой в ядре Linux. Отсутствие исходного кода ядра серьёзно ограничивает создание кастомных прошивок.
