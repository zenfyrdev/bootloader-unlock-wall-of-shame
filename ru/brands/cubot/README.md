# Cubot 

* Вердикт: **ℹ️ «Пока безопасно» :trollface:** (MediaTek)
* Вердикт: **🍅 Ужасно!** (Unisoc)
* [**🔓️ Инструкция по разблокировке (MediaTek)**](../../misc/generic-unlock.md)

Cubot следует [стандартной процедуре разблокировки](../../misc/generic-unlock.md) для своих устройств на MediaTek. Устройства на Unisoc не могут быть разблокированы — это *не* вина Cubot, Unisoc не разрешает разблокировку.

Cubot не публикует исходный код ядра для своих устройств. Это нарушение лицензии GPLv2, используемой в ядре Linux. Отсутствие исходного кода ядра серьёзно ограничивает создание кастомных прошивок и иногда затрудняет получение root-доступа или установку GSI.
