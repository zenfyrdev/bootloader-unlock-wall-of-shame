- [**🔓️ Инструкция по разблокировке (MediaTek)**](../../../misc/generic-unlock.md)

Itel [требует наличия Itel ID](https://en.wikipedia.org/wiki/Bootloader_unlocking) в течение двух недель, прежде чем опция OEM Unlock станет доступна в настройках. После этого можно следовать [стандартной инструкции по разблокировке](../../../misc/generic-unlock.md) для устройств на MediaTek. Устройства на Unisoc не могут быть разблокированы — это *не* вина itel.

Раньше itel не требовал онлайн-подтверждения и двухнедельного ожидания. Времена изменились.

itel не публикует исходный код ядра — это нарушение GPLv2.
