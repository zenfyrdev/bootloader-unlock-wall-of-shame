* [**🔓️ Инструкция по разблокировке**](../../misc/generic-unlock.md)

Shift Phones (https://www.shift.eco/) можно разблокировать через fastboot без каких-либо кодов. Единственное требование — включить **OEM unlocking** в настройках **Для разработчиков** ([стандартная процедура](https://github.com/zenfyrdev/bootloader-unlock-wall-of-shame/blob/main/misc/generic-unlock.md)). Shift также предоставляет тестовые устройства, исходники ядра и камеры — насколько это возможно — чтобы поддерживать кастомные прошивки. У них есть email [devrel@shiftphones.com](mailto:devrel@shiftphones.com) для разработчиков CustomOS.
