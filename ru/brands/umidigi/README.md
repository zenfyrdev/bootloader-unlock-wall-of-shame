# Umidigi

* Вердикт: **🍅 Ужасно!** (Unisoc)
* [**🔓️ Инструкция по разблокировке (MediaTek)**](../../../misc/generic-unlock.md)


Umidigi следует [стандартной процедуре разблокировки](../../../misc/generic-unlock.md) для устройств на MediaTek. Устройства на Unisoc не могут быть разблокированы — это *не* вина Umidigi, Unisoc не разрешает разблокировку.

## Исходный код ядра
Изначально Umidigi **опубликовала исходный код ядра для некоторых своих ранних телефонов** (Umidigi Bison Pro и Umidigi F2) [на GitHub](https://github.com/UMIDIGI-Official?tab=repositories), хотя эти исходники были сломаны, не содержали всех модулей, не имели надлежащих инструкций по сборке, и все проблемы так и остались нерешёнными.

С тех пор **они больше никогда не публиковали исходный код ядра и отвечают на запросы заявлениями, что не могут его предоставить**, тем самым нарушая условия лицензии GPL. Отсутствие исходного кода ядра сильно ограничивает создание кастомных прошивок, а также иногда затрудняет получение root-доступа или запуск GSI.
