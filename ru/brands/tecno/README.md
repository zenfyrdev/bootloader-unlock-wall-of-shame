# Tecno 

- Вердикт: **⚠️ Действуйте осторожно!**
- Вердикт: **🍅 Ужасно!** (Unisoc)

Tecno требует наличия [Tecno ID][Tecno ID] в течение двух недель, прежде чем опция OEM Unlock станет доступна. После этого можно следовать [стандартной инструкции по разблокировке](../../../misc/generic-unlock.md) для устройств на MediaTek. Устройства на Unisoc не могут быть разблокированы — это *не* вина Tecno.

## Исходники ядра
Tecno, несмотря на использование GKI (Generic Kernel Image), не публикует исходный код ядра. Это нарушение лицензии GPL.
